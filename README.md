# Black Star Space — Protótipo 2

Projeto web independente, preparado para Firebase Hosting.

## Uso

```bash
npm install
npm run dev
npm run build
npx firebase login
npx firebase use --add
npm run deploy
```

O vínculo com um projeto Firebase é intencionalmente feito pelo comando `firebase use --add`, para não gravar um identificador de projeto inexistente no repositório.
